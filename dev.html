Integration Guide
OTP Authentication
Verify your users by sending a 6-digit code to their iNet PIN. Expires in 5 minutes.
How it works
1
User enters their iNet PIN
Show a PIN input on your login page.
2
Your backend calls /api/otp/send
iNet sends the code to that PIN. The OTP is returned in the response - store it server-side.
3
User enters the code
They see the OTP in their iNet app and type it into your site.
4
Verify with /api/otp/verify
Returns { valid: true/false }. Log the user in if valid.
Send OTP - JavaScript
javascript (Node.js / backend only)
// STEP 1: Send OTP to user's PIN
const res = await fetch('https://emltechstudio-inet-v2.hf.space/api/otp/send', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': process.env.INET_API_KEY
  },
  body: JSON.stringify({ net_number: userPin })
});
const { otp } = await res.json();
// Store otp in your session/db against this user
session.pendingOtp = otp;
session.pendingPin = userPin;
Verify OTP - JavaScript
javascript (backend)
// STEP 2: Verify when user submits the code
const res = await fetch(
  `https://emltechstudio-inet-v2.hf.space/api/otp/verify?net_number=${userPin}&otp=${userEnteredCode}`,
  { method: 'POST' }
);
const { valid } = await res.json();
if (valid) {
  createUserSession({ pin: userPin });
} else {
  respondWithError('Invalid or expired code');
}
OTPs expire after 5 minutes. Never verify on the frontend - always call the verify endpoint from your backend server.

Continue with iNet
Add iNet as an auth provider. Users sign in with their PIN + OTP. No passwords, no Google, no email.

Full Flow
1
User clicks "Continue with iNet"
Your app collects the device fingerprint and sends it to iNet.
2
iNet returns matching accounts
Call /api/login-with-inet with the fingerprint. iNet returns all PINs linked to that device.
3
User picks an account
Show a chooser: "Which account do you want to use?" The user selects one PIN.
4
Send OTP to verify
Call /api/otp/send for the chosen PIN. User enters the code to complete login.
javascript - full example
// 1. Get device fingerprint
async function getFingerprint() {
  const components = [
    navigator.userAgent, navigator.language,
    screen.width + 'x' + screen.height,
    navigator.hardwareConcurrency
  ];
  const hash = await crypto.subtle.digest('SHA-256',
    new TextEncoder().encode(components.join('::')));
  return Array.from(new Uint8Array(hash))
    .map(b => b.toString(16).padStart(2, '0')).join('');
}

// 2. Call Continue with iNet
async function loginWithInet() {
  const fp = await getFingerprint();
  const res = await fetch('/api/login-with-inet', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': process.env.INET_API_KEY
    },
    body: JSON.stringify({ fingerprint: fp })
  });
  const { accounts } = await res.json();

  // 3. Show account chooser
  const pin = await showAccountChooser(accounts);

  // 4. Send OTP
  await fetch('/api/otp/send', {
    method: 'POST',
    headers: { 'X-API-Key': process.env.INET_API_KEY },
    body: JSON.stringify({ net_number: pin })
  });

  // 5. Verify OTP
  const code = prompt('Enter code from iNet app:');
  const vfy = await fetch(
    `/api/otp/verify?net_number=${pin}&otp=${code}`,
    { method: 'POST' }
  );
  const { valid } = await vfy.json();
  if (valid) createSession(pin);
}

Integration Guide
Send Messages
Push any text or HTML to an iNet user. Rendered like an email inside the app. Delivered via WebSocket if online, push notification if not.
We forward your content as-is. HTML is rendered exactly like Gmail renders HTML email. No filtering, no restrictions - your responsibility.
Send plain text
javascript
await fetch('https://emltechstudio-inet-v2.hf.space/api/send', {
  method: 'POST',
  headers: { 'X-API-Key': YOUR_KEY, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    net_number: '487291',
    type: 'text',
    content: 'Your order has been confirmed!',
    developer_name: 'Trades'
  })
});
Send HTML
python
requests.post(
    'https://emltechstudio-inet-v2.hf.space/api/send',
    headers={'X-API-Key': YOUR_KEY},
    json={
        'net_number': '487291',
        'type': 'html',
        'content': '''
<h2 style="color:#e63946">Welcome to Trades!</h2>
<p>Your account is ready.</p>
<a href="https://trades.app/start">Get started →</a>
''',
        'developer_name': 'Trades'
    }
)
